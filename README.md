# test_init_project

> Depot de test pour verifier l'initialisation d'un nouveau projet avec Git et GitHub.

## A propos

Ce depot sert a tester le parcours initial d'un projet : creer une branche de developpement, effectuer un premier commit, puis envoyer le depot local vers GitHub.

## Objectifs

- Verifier que le depot local est correctement initialise.
- Effectuer le premier commit sur la branche `develop`.
- Verifier que le push vers GitHub fonctionne.

## Parcours de test

1. Creer ou selectionner la branche `develop`.
2. Ajouter les fichiers du projet.
3. Effectuer un premier commit.
4. Connecter le depot local a son depot GitHub.
5. Envoyer la branche `develop` vers GitHub.

## Etat du projet

Depot de test en cours d'initialisation. Il ne contient pas encore d'application ni de fonctionnalites a executer.
